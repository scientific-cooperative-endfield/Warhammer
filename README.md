# Warhammer — «Последний час Ереси»

Процедурная 2.5D-анимация в стиле папье-маше о последних часах Ереси Хоруса (Warhammer 30k).
Всё в одном файле `index.html`: HTML + CSS + JavaScript, без картинок, шрифтов и библиотек.

**Запуск:** откройте `index.html` в браузере (работает и с `file://`).

## Что внутри
- ~3:20 хронометража, 9 глав: галактика в огне → орбита Терры → стены Дворца → щиты опущены →
  Сангвиний против Хоруса → Император против Хоруса → Олланий Пий → Золотой Трон → эпилог.
- Персонажи-марионетки из «вырезанной бумаги» на латунных шплинтах: Хорус, Император, Сангвиний,
  Рогал Дорн, Константин Вальдор, Олланий Пий, Ка'Банда, кустодии, титаны, флоты.
- Планы: режиссёрский, общий, крупный; **Терра с орбиты** (попиксельная сфера с пожарами Дворца),
  **карта галактики** (маршрут Хоруса, Око Ужаса, Астрономикон) и режим **присутствия варпа**.
- Перемотка в обе стороны, воспроизведение назад, скорость ×0.25–×4, покадрово, главы, ±10 с.
- Настройки: качество (авто), stop-motion 8/12/24 к/с, текстура бумаги, глубина теней, параллакс
  (касание/гироскоп), сила варпа, тон, субтитры, карточки, тряска, звук, автоскрытие, FPS.
- Мобильная оптимизация: адаптивный масштаб под портрет/ландшафт, safe-area, жесты (свайп —
  параллакс, щипок — зум, двойной тап — перемотка), авто-снижение качества, рендер «по требованию»
  на паузе, пауза при сворачивании.

Всё состояние кадра — чистая функция времени, поэтому перемотка назад работает без симуляции.

Параметры URL для отладки: `?t=120&view=close&warp=1&play=1` (view: `dir|wide|close|orbit|map`).
